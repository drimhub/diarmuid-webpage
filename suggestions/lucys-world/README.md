# Lucy's world

A cute, sparkly pixel-art meadow where young bulls and feral hogs (drawn as sprites) wander and play together.

- Tap an animal to make it hop and shower sparkles.
- Tap the emoji buttons to send floating emoji and keep a count.
- Leave a comment: it appears as a speech bubble from a random animal and in a feed below.

Comments and emoji counts live only in the open page. Saving them for other visitors would need a shared backend, which suggestions don't have.

Plain HTML/CSS/JS, no build step.
