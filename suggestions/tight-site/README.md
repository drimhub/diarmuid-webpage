# This is a tight site!

A web 1.0 party page: a live timestamp and a bunch of colourful phrases ("This site is tight!", "This is a tight site!", ...) bouncing around the screen, changing colour on every wall hit.

- `index.html`, `style.css`, `script.js`: plain static files, no build step.
- Respects `prefers-reduced-motion` (phrases stay still).
- Nothing is stored.

Suggested in issue #11.
