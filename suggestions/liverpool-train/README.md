# Cian and Diarmuid's trip to Liverpool

A cutesy old-timey train for the London to Liverpool trip. Choo choos, chugga chuggas and puffs of smoke.

- "Add photos from a stop" adds a train carriage per photo. Each carriage has a box to name the stop.
- "Upload Cian's face" puts a photo of Cian on the fat conductor's face.
- Photos are held in memory for the visit only. Nothing is uploaded, saved or shared. "Reset" clears them.
- Keeping photos or stop names between visits would need a backend, which a static page can't have.

Files: `index.html`, `style.css`, `script.js`.
