# Jennifer's world

Bunnies and drim rain down around Jennifer. Tap one to send it flying to her for a kiss; a counter tracks the kisses.

- Drim shows as a cartoon face by default. Visitors can add their own drim pictures.
- Visitors can upload a photo of Jennifer, which replaces her cartoon face.
- Pictures are held in memory for the visit only. Nothing is uploaded, saved or shared. "Reset pictures" clears them.
- Keeping pictures or the kiss count between visits would need a backend, which a static page can't have.

Files: `index.html`, `style.css`, `script.js`.
